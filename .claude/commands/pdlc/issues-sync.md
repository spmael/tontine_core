For `$ARGUMENTS`, prepare a dry-run summary containing:

- task or capability ID and title;
- requirements and acceptance criteria;
- current status, dates, and validation evidence;
- proposed issue title and body.

Stop after presenting the summary. External issue creation requires a separately
approved repository target and explicit confirmation.
