---
description: Create capability or task records for uncovered package requirements.
argument-hint: <domain capability>
---

There are no application stories in this repository. For the requested domain,
read the requirements register and existing capability/task records.

1. Identify uncovered requirements.
2. Propose a capability or task using the bundled templates.
3. Include explicit invariants, exclusions, acceptance criteria, tests, dates,
   and validation commands.
4. Do not mark new work `ready` or `shipped` without review and evidence.
5. Present the proposed records before writing them.
